Туториал: как сделать DinoGoogle

От пустого HTML-файла до работающей игры. 9 шагов с кодом и объяснениями — на чистом HTML, CSS и JavaScript.

📄 9 шагов ⏱ ~30 минут ⚡ Без фреймворков

01

Что понадобится

Для этой игры не нужны фреймворки, библиотеки и сборщики. Достаточно браузера и трёх файлов.

  • index.html — структура страницы
  • style.css — внешний вид и анимации
  • script.js — логика игры

Также нужны два спрайта: динозаврик и кактус. Можно нарисовать самому или взять готовые пиксельные картинки.

Совет: спрайты удобно хранить в папке assets/img/. Тогда пути будут вида assets/img/dino.png.
02

HTML-каркас

Создаём базовую страницу с игровым полем и двумя элементами внутри: динозавриком и кактусом.

index.html 
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>DinoGoogle</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="game">
        <div id="dino"></div>
        <div id="cactus"></div>
    </div>

    <script src="script.js"></script>
</body>
</html>

Пока на странице ничего не видно — два пустых div'а без стилей. Это нормально, дальше будем их оформлять.

03

Стили поля

Задаём размеры игрового поля и рисуем линию земли. Используем position: relative на контейнере — чтобы дети позиционировались относительно него.

style.css 
.game {
    width: 600px;
    height: 200px;
    margin: 0 auto;
    border-bottom: 2px solid #000;
    position: relative;
    overflow: hidden;
}

border-bottom — это линия земли. overflow: hidden обрезает всё, что вылезает за пределы поля.

04

Динозаврик

Добавляем спрайт динозаврика как background-image и ставим его слева внизу. Используем position: absolute и bottom: 0 — так он «стоит» на линии земли.

style.css 
#dino {
    width: 50px;
    height: 50px;
    background-image: url("assets/img/dino.png");
    background-size: 50px 50px;
    background-repeat: no-repeat;
    position: absolute;
    bottom: 0;
    left: 50px;
}
Почему bottom, а не top: при bottom: 0 динозаврик «прилипает» к линии земли. Если потом анимация будет двигать его по вертикали — удобнее менять bottom от 0 до 95px.
05

Кактус

Кактус ставим справа, за пределами видимой области. Он будет заезжать в поле, когда игра начнётся.

style.css 
#cactus {
    width: 20px;
    height: 40px;
    background-image: url("assets/img/cactus.png");
    background-size: 20px 40px;
    background-repeat: no-repeat;
    position: absolute;
    bottom: 0;
    left: 100%;  /* за правым краем */
}

left: 100% означает «правый край родителя». Кактус не виден — он за пределами поля.

06

Прыжок

Прыжок делаем на CSS-анимации. Когда на динозаврика добавляется класс .jump, срабатывает @keyframes, и он подпрыгивает.

style.css 
.jump {
    animation: jump 0.6s linear;
}

@keyframes jump {
    0%   { bottom: 0; }
    25%  { bottom: 40px; }
    50%  { bottom: 95px; }
    75%  { bottom: 40px; }
    100% { bottom: 0; }
}

Теперь JS. Слушаем нажатие клавиш и добавляем класс на 600 мс:

script.js 
const dino = document.getElementById("dino");

document.addEventListener("keydown", function (e) {
    if (e.code === "Space" || e.code === "ArrowUp") {
        e.preventDefault();
        jump();
    }
});

function jump() {
    if (!dino.classList.contains("jump")) {
        dino.classList.add("jump");
        setTimeout(() => {
            dino.classList.remove("jump");
        }, 600);
    }
}
Почему setTimeout 600 мс: ровно столько длится CSS-анимация. Если снять класс раньше — динозаврик дёрнется.
07

Движение кактуса

Сначала попробуем двигать кактус через CSS-анимацию — это просто, но у способа есть проблема: при перезапуске игры анимация сбрасывается некорректно, и кактус «телепортируется» к динозаврику. Поэтому в стартовой версии движение вынесено в JavaScript.

Используем requestAnimationFrame — встроенный метод браузера, который вызывает функцию ~60 раз в секунду. Это оптимальный способ для игрового цикла.

Важно учитывать delta time — сколько миллисекунд прошло с прошлого кадра. Без этого скорость игры будет зависеть от частоты обновления экрана: на быстром мониторе кактус полетит быстрее, на слабом — медленнее.

script.js 
const cactus = document.getElementById("cactus");
const game = document.getElementById("game");

let cactusX = 0;
let speed = 240;       // пикселей в секунду
let lastTime = 0;
let rafId = null;

function loop(timestamp) {
    if (!lastTime) lastTime = timestamp;
    const deltaSec = (timestamp - lastTime) / 1000;
    lastTime = timestamp;

    // Двигаем кактус влево
    cactusX -= speed * deltaSec;

    // Если уехал за левый край — вернуть направо
    if (cactusX < -40) {
        cactusX = game.clientWidth + 100;
    }

    cactus.style.transform = `translateX(${cactusX}px)`;

    rafId = requestAnimationFrame(loop);
}

// Старт
cactusX = game.clientWidth + 50;
rafId = requestAnimationFrame(loop);
Зачем deltaSec: если компьютер мощный — кадры идут 60 раз в секунду, если слабый — 30. Без дельты кактус на слабом ПК ехал бы медленнее. С дельтой скорость одинакова везде.

Чтобы кактус был виден, надо ещё поменять CSS: вместо left: 100% поставить left: 0 — позицией будет управлять JS через transform.

style.css 
#cactus {
    width: 20px;
    height: 40px;
    background-image: url("assets/img/cactus.png");
    background-size: 20px 40px;
    background-repeat: no-repeat;
    position: absolute;
    bottom: 0;
    left: 0;
    transform: translateX(600px);  /* стартует за правым краем */
    will-change: transform;            /* оптимизация */
}
08

Коллизия и Game Over

Проверяем, пересекаются ли прямоугольники динозаврика и кактуса. Используем getBoundingClientRect() — он возвращает координаты элемента на экране.

script.js 
function checkCollision() {
    const dinoRect = dino.getBoundingClientRect();
    const cactusRect = cactus.getBoundingClientRect();
    const pad = 4;  // прощаем лёгкие касания

    const overlap =
        dinoRect.right - pad > cactusRect.left + pad &&
        dinoRect.left + pad < cactusRect.right - pad &&
        dinoRect.bottom - pad > cactusRect.top + pad;

    if (overlap) gameOver();
}

function gameOver() {
    cancelAnimationFrame(rafId);
    alert("GAME OVER");
    // позже заменим alert на красивый оверлей
}

Проверять коллизию надо прямо в игровом цикле — после того, как кактус сдвинулся:

script.js — в функции loop() 
cactus.style.transform = `translateX(${cactusX}px)`;

checkCollision();  // проверяем прямо тут

rafId = requestAnimationFrame(loop);
Как работает overlap: это условие истинно, когда прямоугольники пересекаются. Если хоть одно из четырёх условий ложно — пересечения нет.
09

Счёт, рекорд и ускорение

Счёт увеличиваем каждые 150 мс через setInterval. Рекорд сохраняем в localStorage — он переживёт перезагрузку страницы.

script.js 
let score = 0;
let best = Number(localStorage.getItem("dino-best") || 0);

// Счёт: +1 каждые 150 мс
setInterval(() => {
    score++;
    scoreEl.textContent = score;
}, 150);

// При Game Over — сохраняем рекорд
function gameOver() {
    if (score > best) {
        best = score;
        localStorage.setItem("dino-best", best);
    }
    // ...показать оверлей
}

Ускорение: каждые 4 секунды увеличиваем speed на 20 пикселей в секунду, пока не дойдём до максимума. Это делает игру постепенно сложнее, но не превращает её в кашу.

script.js 
const maxSpeed = 500;
const speedStep = 20;

setInterval(() => {
    if (speed < maxSpeed) speed += speedStep;
}, 4000);
localStorage хранит данные в браузере. Они не удаляются при перезагрузке, но привязаны к конкретному браузеру и устройству. Идеально для рекордов.
